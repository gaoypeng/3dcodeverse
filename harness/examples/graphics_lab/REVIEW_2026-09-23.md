# Graphics library maintenance and expansion — September 23, 2026

This record covers the expanded gallery and shared library after the earlier
[water and material refinement](REFINEMENT.md). All examples, shader sources,
comments and gallery controls are English. Images are rendered from scene code;
there are no generated backgrounds or downloaded photographic textures.

## Library changes

All 50 original modules have an explicit disposition in the four family audits.
Forty-seven received visual, numerical, composition or resource-ownership fixes;
`caustics`, `finish` and `ocean` were retained with recorded justification. The
current library has 58 modules and 190 named exports. Seven additions provide
trees/shrubs, bounded volume clouds, smoke/steam, fractured ice, falling water,
paving and shared flame/soot fields. `lifecycle` is the eighth addition, for owned
resource cleanup. The inventory preserves the original 50 source hashes.

Water maintenance corrects transformed reflection planes, nested renderer-state
restoration, attached-object transforms, finite HDR edges and graded stream-bed
sampling. Cloud support no longer regrows against its proxy walls as noise moves.
Vegetation, terrain, rain coverage, walking contact, material normals and borrowed
resource ownership have separate behavioral and actual GPU checks. The rain scene
uses lower-detail background leaves while preserving leaf placement/count; its
tested geometry falls from 20.7 to 12.4 million triangles.

The gallery contains 16 authored studies and three agent cases. The original six
remain first. Additional studies cover trees, clouds, smoke, ice, waterfalls, rain,
worked materials, campfire/bonfire, a burning structure and an independent shader.
Agent provenance distinguishes original Luna CLI output from later delegated
refinements. No new paid model API call was made during this maintenance pass.

## Fire at several scales

[`makeFireField`](../../codeverse3d/languages/scene_threejs/starter/src/lib/firefield.js)
combines up to 16 emitters into one bounded flame/soot volume, with rising embers
and up to four practical lights. An optional depth pass over explicit borrowed
opaque objects terminates rays at visible walls or fuel. Sources share a baked
atlas, avoiding a per-sample loop over every emitter. The original candle and
small-fire API remains available.

[Campfire](scenes/campfire.js) includes close fuel/ember and large open-fire cameras.
[Structural fire](scenes/structural_fire.js) places a shared field through actual
window and roof openings, with whole-house, window and roof views. The examples
use the shipped library, with scene-specific ground, timber and lighting.

Balanced quality uses an approximately 1.49 MB atlas/noise allocation, 80 view
samples and five soot-light samples; high uses approximately 2.49 MB, 128 and
seven. Optional opaque depth adds a pass over the supplied occluders. These are
bounded rendering costs, not isolated frame-rate measurements.

This is prescribed turbulent transport. It does not solve combustion, fuel
consumption, ventilation, structural collapse or fire spread. Bright windows can
saturate and fine ray-march grain remains visible in large wisps. Glass and several
overlapping transparent volumes are not resolved by the opaque-depth pass. The
authored cottage and vegetation remain recognizably procedural.

## Independent GLSL

[The alloy study](scenes/external_shader.js) loads separate
[vertex](shaders/external_shader.vert), [fragment](shaders/external_shader.frag)
and [helper](shaders/external_shader_common.glsl) files using `THREE.FileLoader`
inside asynchronous scene creation. `ShaderMaterial` uses `THREE.GLSL3`;
JavaScript supplies geometry, uniforms and absolute-time updates. The runtime
serves these local files and maps external compiler errors back to source lines.
The gallery builder, capture records and transfer packager preserve their bytes
and SHA-256 values. Direct browser imports of raw shader text need a loader;
desktop OpenGL host programs need adaptation to WebGL and GLSL ES.

The alloy appearance is an artistic analytic studio response. It is not a measured
anodization model or scene-wide ray tracing.

Visual review also retains broader limits: distant mountain geometry is coarse,
some rocks have conspicuously faceted silhouettes, and cloud billows remain
strongly authored. Reflections and transmission improve depth cues but do not
turn the water into a free-surface fluid solver. These are useful executable
effect studies, not a claim of photographic realism across every gallery view.
